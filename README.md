# Aphelios 我的待办 Widget 演示

基于项目中的设计图制作的离线页面演示。无需安装依赖或访问外网，直接用现代浏览器打开 `index.html` 即可。

支持类型、状态和优先级筛选，分页、多选、单项及批量模拟派发、任务详情和状态展示。数据保存在页面内存中，刷新后恢复初始状态；AgentSpace 跳转和任务派发均为演示，不会调用后台。后续接入公司环境时，可在 `app.js` 中替换数据和操作逻辑。

## 部门和来源系统演示

页面尝试读取名为 `department` 的普通 Cookie，并根据部门查找 `app.js` 中的 `departmentSources` 示例映射。页面上可选择“演示部门”切换示例；选择“使用 Cookie”恢复自动读取。已按部门配置类别及来源系统，选择全部时展示所有类别的来源，选择单个类别时仅展示该类别的来源；未识别部门或缺少映射时显示未配置。

直接以 `file://` 打开时浏览器可能不支持读取 Cookie，可使用页面上的演示部门选择器。若要测试 Cookie，使用本地 HTTP 服务打开页面，例如在项目目录执行 `python -m http.server 8000`，访问 `http://localhost:8000/`，在浏览器开发者工具控制台执行 `document.cookie = "department=" + encodeURIComponent("公共产品开发与IT装备部") + "; path=/"`，然后刷新。

实际接入需明确公司身份 Cookie 的名称和格式、用户部门接口、部门与来源系统映射及数据接口。HttpOnly Cookie 无法由 JavaScript 读取；应由服务端通过已认证会话识别用户并返回部门和授权后的来源配置，不能把客户端 Cookie 或演示选择器作为授权依据。

MAE-CN 演示中将 FE 样例展示为 IR，并增加 SR 样例；这些待办仅用于展示，不代表实际业务数据。切换部门会清除已选项目。

选择 MAE-CN 产品部后，对待处理的 US 下发任务可体验执行方案选择；Workflow / Agent 名称和角色标记为交互示例。混合类别批量选择时提示分开下发。
