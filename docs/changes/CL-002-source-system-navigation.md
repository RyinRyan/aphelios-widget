## 本轮页面变更

**待办列表补充独立的“前往原系统”入口，保留详情内的来源跳转。**

| 位置 / 入口 | 变更前 | 变更后 |
|---|---|---|
| 列表来源区域 | 仅展示来源名称，跳转入口位于详情 | 存在有效对象地址时直接展示“前往原系统” |
| 待办标题 | 点击查看详情 | 继续查看详情，不与来源跳转混用 |
| 详情 | 存在对象地址时可跳转 | 保留该入口及详情内下发操作 |
| 未配置对象地址 | 详情提示未配置 | 列表和详情均给出说明，不生成假地址 |

体验路径：打开 [demo](../../demo/index.html)，查看每条待办来源区域；当前样例没有真实 `sourceUrl`，因此显示“原系统地址未配置”。点击标题打开详情，继续查看和使用任务操作。为样例提供有效 HTTP(S) 对象地址后，列表和详情出现跳转链接，在新标签页打开该对象。

## 本轮明确的规则

原表格 demo 的跳转原系统能力必须保留。对象详情、原系统跳转、AgentSpace 任务跳转是不同用途的入口；原系统链接指向具体业务对象，不以原系统首页替代。
