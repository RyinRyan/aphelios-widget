## 明确的执行流程

理解现状 → 提问工具澄清 → 明确规格 → 更新组件 demo → HTTP 实际调测 → 发现问题立即修复复测 → 截图嵌入当轮澄清文档 → 校验、自动 commit 并推送，核对远端后报告交付状态。

重点经验：业务入口归属 Widget；部门和空间各有职责；配置规则先澄清再实施；自适应不能仅靠换行；验收同时检查布局质量与操作效果；截图应覆盖关键状态并确保资源为最新；每轮文档独立记录、索引倒序，同时刷新当前设计规格。
