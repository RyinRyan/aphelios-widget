## 背景与目标

同一类别业务对象可能对应不同工作目标。用户可为对象类别配置执行方案，并在下发任务时选择；系统将选择结果写入统一事件，供 AgentSpace 事件任务筛选。

## 范围与角色

方案绑定 Widget 所在的 AgentSpace 空间，空间标识由工作台提供，用户无需选择。当前空间中所有可访问用户均可创建和管理方案，空间访问由 AgentSpace 现有权限机制管理。方案管理包括查看、创建、编辑、停用、重新启用和删除。

Widget 与工作台通过发布事件触发任务，不直接拉起 Workflow 或 Agent，也不创建或配置 AgentSpace 事件任务。用户在 AgentSpace 手动配置事件筛选条件。

## 方案信息与规则

| 字段 | 规则 |
|---|---|
| 空间 | 使用工作台提供的当前空间标识 |
| 对象类别 | 仅可选择当前空间使用的对象类别，不展示全量类别；以空间配置为依据，不以当前分页的数据或数量判断 |
| 中文展示名称 | 用户填写，用于界面展示 |
| 英文方案名称 | 用户填写；仅允许英文字母、数字、下划线；创建后不可修改 |
| 方案说明 | 用户填写，描述工作目标 |
| 常用角色 | 用户填写，用于展示适用角色 |
| 状态 | 启用或停用 |

同一空间、同一对象类别内英文方案名称唯一；不同类别可重复。方案可修改中文名称、说明和常用角色，英文名称及关联类别保持不变。停用期间方案不出现在下发选项中，可重新启用。删除前须二次确认；停用或删除不改变历史任务记录，历史任务保留创建时的中文方案名称和英文标识。

## 下发及事件规则

1. 用户下发对象时，展示当前空间中该类别已启用的方案供选择。
2. 无已启用方案时，允许按原有方式下发，事件不包含 `executionPlan`。
3. 选择方案后，统一 Webhook 在顶层增加 `executionPlan`，其值为方案英文名称。原有 `eventType` 保留。
4. 用户在 AgentSpace 手动配置 Event Task，通过 `eventType` 和 `executionPlan` 联合筛选。
5. 下发任务时保存方案名称和英文标识快照，用于历史展示。

示例：

```json
{
  "id": "event-001",
  "eventType": "US_ANALYSIS",
  "executionPlan": "software_design",
  "data": { "objectId": "US-3350" }
}
```

示例 `eventType` 仅用于说明字段结构，不是已确定的事件类型。

## 界面与异常

“我的待办” Widget 内的配置入口提供方案列表、状态、编辑、停用/启用和删除操作。创建表单填写上述方案信息；英文名称不符合字符规则或同空间同类别重复时阻止保存并提示。删除前要求确认。下发界面只展示当前类别已启用方案；无方案时使用原有流程。

## 验收标准

- 创建方案的类别选项与当前空间使用的对象类别一致，即使某类别当前没有待办，也应保留该选项。
- 同空间可访问用户可查看和管理该空间方案；其他空间方案不显示。
- 同类别英文名称重复或含非法字符时不能创建，不同类别允许相同英文名称。
- 已创建方案的英文名称不能编辑；中文名称、说明和角色可编辑。
- 停用方案不出现在下发选项中，重新启用后恢复；删除须二次确认。
- 有选择方案的事件包含顶层 `executionPlan` 和原有 `eventType`；无启用方案时按原有事件格式下发。
- 方案编辑、停用或删除后，已创建任务仍显示创建时的方案名称和英文标识。
